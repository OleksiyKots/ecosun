# Ecosun

Адаптивний лендинг компанії з монтажу сонячних електростанцій.

**Демо:** https://oleksiykots.github.io/ecosun/

## Технології
- HTML5, CSS3 (Flexbox, media queries, transition, @keyframes)
- Без JavaScript і фреймворків

## Структура
- `index.html` — розмітка сторінки
- `css/style.css` — стилі
- `img/`, `video/` — зображення та відео

## Запуск
Відкрийте `index.html` у браузері.
